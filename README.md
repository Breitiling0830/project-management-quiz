# 國際專案管理期中考刷題

線上練習：https://breitiling0830.github.io/project-management-quiz/

## 題庫

- `期中考範圍.xlsx`：選擇題工作表，150 題，保留題號、選項及標準答案。
- `專案管理計算題期中考.docx`：9 題計算選擇，原題號 1、2、9～15，保留原檔解題步驟。
- 共 159 題，沒有補造 Word 缺少的題號。

Excel 原檔未提供解析，網站的觀念解析為補充整理。部分來源答案或用語有疑義，網站仍依附件標準答案計分，並於相關題目附上說明；例如 Excel 第 55、134 題建議向教師確認。

## 功能

觀念／計算題庫切換、主題練習、依題號練習、隨機抽題、錯題複習、題目與選項搜尋、公式速查、逐題判分、每輪成績、計算草稿、自動保存與繼續練習。支援手機與深色模式。

單一 `index.html`，無外部 JS／CSS 套件，直接開啟或用 GitHub Pages 即可使用。紀錄保存在當前瀏覽器 localStorage，不上傳、不跨裝置同步，與投資學網站使用不同儲存鍵。

## GitHub Pages

Settings → Pages → Deploy from a branch → main → / (root)。
